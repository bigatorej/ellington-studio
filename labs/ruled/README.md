# Ruled. Playground

A decision log for leaders. Say what you decided, why, and when to check it. Ruled files it, brings it back on the review date, and shows you which kinds of decisions go well.

One file, `index.html`. No build, no framework, no server, no keys, no network beyond Google Fonts. It is the file Claude Code deploys at `/labs/ruled/` on the Ellington Studio site.

## The views

| Tab | What it does |
|---|---|
| Log | Every ruling as a card with the Oxblood RULED stamp, the decision in serif on ruled lines, the reasoning, tags, decided date, review countdown and the outcome squares once reviewed. "Ask the log" searches decision, reasoning, tags and outcome notes, strips filler ("what did I decide about"), and highlights the matching words. Status and tag chips filter. Tap a card for the detail sheet: all fields, Edit, Review now, Copy as text, Delete with an inline confirm. |
| Rule | The capture view. A big Oxblood "Say it" button uses the browser's speech recognition where it exists and shows a live transcript. Where it does not, the button reads "Type instead" and focuses the text box. The sentence is split into decision, because, tags, review date and confidence, and a form shows the split for a final check. "Rule it" files it with a stamped toast and lands on the Log. |
| Review | The count line ("4 due, 2 coming up, 2 reviewed this quarter"). "Due now" lists rulings at or past their review date, oldest first, each with Review now and Push the review (2 weeks, 1 month, 3 months). The review sheet asks "How did it turn out?" with five score squares, an outcome note, and a "What would you do differently" box that appears at score 3 or below. "Coming up" lists the next 30 days and marks this week. |
| Read | The quarterly read. Period selector (This quarter, Last quarter, All time) on the decided date. Four tiles: rulings made, reviewed on time rate, average score, velocity in rulings a week. By tag bars coloured by score band. A 5 by 5 confidence against outcome heat map drawn with CSS grid. A Patterns card of 3 to 5 sentences generated by rules. Export as CSV, JSON or Markdown, and a sample read only link with a copy button. |
| Settings | Reached from the gear in the top bar. Name, company, default review window (30, 45, 60, 90 days), week start, download the log as JSON, import a JSON file, Reset to seed with inline confirm, the "How this playground works" card, and the Ellington Enterprises monogram line. |

## How state works

- One JSON document in `localStorage` under the key `labs.ruled.v1`: `{ version, tab, readPeriod, settings, rulings[] }`.
- Each ruling: `id` (R-0001 style, shown on screen as R·0001), `decision`, `reasoning`, `tags[]`, `decided`, `review`, `confidence` 1 to 5, `status` (open, due, reviewed), `score`, `outcome`, `differently`, `reviewedOn`. Dates are ISO in the data and formatted month first with the ordinal everywhere a person reads them.
- `status` is recomputed on load and after every change: a ruling with a score is reviewed, one at or past its review date is due, everything else is open.
- Every storage read and write is wrapped in try and catch. If storage throws, the app runs in memory for the session.
- The current tab and the Read period persist. Search text and filter chips do not.
- The seed is relative to today, so the due list, the coming up list and the quarter tiles always have something on them.

## What is simulated, and what replaces it

| Playground | What it does here | Real service in the shipped app |
|---|---|---|
| Voice capture | `webkitSpeechRecognition` in Chrome and Safari with a live transcript. "Type instead" elsewhere. | Claude speech to text through the app's backend, every browser. |
| The split | `parseRuling(text)`: rule based. Splits on because, since, so that, given that. Pulls "review in 6 weeks", "check in 2 weeks", "revisit on November 20". Tags from #tags and a whole word keyword map. Confidence from "I am sure", "pretty sure", "not sure". Dollar amounts tag Money; "from $X to $Y" tags Pricing too. | Claude reads the sentence and returns the fields with a confidence of its own. |
| Patterns | Template sentences built from the user's own numbers: highest and lowest tag, on time rate, confidence against outcome, velocity. | Claude writes the quarterly read from the same numbers. |
| Share a read only link | A sample URL derived from the company name, with a copy button. | A real read only page with accounts and sync. |

Marked in the UI with a dashed "Playground" chip wherever one of these appears.

```
node /home/claude/ellington-studio/scripts/check-copy.mjs /home/claude/ellington-studio/labs/ruled/index.html
```

2. Playwright acceptance run. Serves this folder on a free port, runs the six acceptance tests from the spec at 390 by 844 and 1440 by 900, and writes screenshots to the deliverable folder in OneDrive (`15 Ellington Labs 2026.10.21/playgrounds/`):

```
python3 /tmp/claude-0/-home-claude/4d02d115-62b7-5012-83cd-c1bc9a5919c7/scratchpad/labs/test-ruled.py
```

## Palette and type

Ink `#15171C`, Paper `#F5F2EA`, White, Rule `#D9D3C4`, Oxblood `#7A1F2B` (the one action colour), Graphite `#3A3D45`, Stone `#767A84`, Olive `#5B6B3A`, Mustard `#B8891F`, Clay `#A3452F`. Caption text uses a darker Stone (`#666A74`) and due text a darker Mustard (`#8A6414`) so small text meets 4.5 to 1. IBM Plex Serif 600 for headings and decisions, IBM Plex Sans 400 and 500 for body, IBM Plex Mono 400 for dates and ids. Cards carry faint ruled lines at 28px spacing behind the decision text and a thin Oxblood margin line, like a legal pad.

Fictional company throughout: Harbor Lane Coffee, four shops, 14 seeded rulings.
